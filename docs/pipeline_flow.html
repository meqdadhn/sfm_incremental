Pipeline::Run, step by step

How sfm_main config.yaml turns images into poses, a point cloud and an orthophoto. Rectangles are functions; slanted boxes are the data each function hands to the next; cylinders are on-disk caches.

Top level: Pipeline::Run()

flowchart TD
  CFG[/"config.yaml"/] --> LC["sfm_main: LoadConfig()"]
  LC --> SC[/"SfmConfig"/]
  SC --> RUN(["Pipeline::Run()"])
  RUN --> L["1 · LoadImages()
ListImages, LoadTrajectoryPriors,
imread to fill camera width/height"]
  L --> D1[/"rec_.images: id, name, path, camera_id, GPS prior
rec_.cameras: intrinsics + image size"/]
  L -.-> TP[/"output/trajectory_priors.txt"/]
  D1 --> F["2 · ExtractFeatures()  (OpenMP per image)
imread gray → ExtractSift → UndistortKeypoints"]
  F <-.-> C1[("cache/features/*.sift")]
  F --> D2[/"per image: keypoints, descriptors,
undistorted normalized coords"/]
  D2 --> M["3 · MatchAndEstimateRops()  (OpenMP per pair)
SelectPairs → MatchDescriptors →
EstimateTwoViewGeometry (essential matrix RANSAC)"]
  M <-.-> C2[("cache/rops.bin")]
  M --> D3[/"view_graph_: verified pairs with
inlier matches + relative R, t
(descriptors released)"/]
  D3 --> I{"4 · RunIncremental()
IncrementalMapper::Run()"}
  I -- "no seed pair" --> FAIL(["return false → exit 2"])
  I -- ok --> D4[/"registered image poses, sparse 3D points,
seed1_ / seed2_ (gauge)"/]
  D4 --> T["5 · FinalTrackingAndBundle()
BuildTracks → TriangulateTracks →
N × (RunBundleAdjustment + FilterPoints)"]
  T --> D5[/"refined poses, points,
optionally refined intrinsics"/]
  D5 --> E["Export()
ColorizePoints → WriteColmapText,
WritePly, WritePoses, WriteEopsOPK"]
  E --> O1[/"output/colmap/, points.ply,
poses.txt, eops_opk.txt"/]
  O1 --> Q{"ortho.enabled?"}
  Q -- yes --> G["6 · GenerateOrtho()
GenerateOrthophoto → WriteOrthophoto"]
  G --> O2[/"output/ortho/ortho.png"/]
  O2 --> DONE(["return true → exit 0"])
  Q -- no --> DONE
▭function ▱data passed on / file written ⛁cache (keyed by a hash of the relevant config) ◇branch

Note the order in Run(): Export() runs before GenerateOrtho(), so the reconstruction files are written even if the orthophoto fails.

Inside step 4: IncrementalMapper::Run()

Grows the model one image at a time from a seed pair, with periodic bundle adjustment. Lives in src/incremental_mapper.cpp.

flowchart TD
  S(["IncrementalMapper::Run()"]) --> IN["Initialize()
rank images by number of verified neighbors,
neighbors by inlier count"]
  IN --> SP{"next candidate pair passes?
triangulation angle ≥ seed_min
homography ratio ≤ seed_max"}
  SP -- "no, try next" --> SP
  SP -- yes --> IFP["InitializeFromPair(a, b)
a = identity, b = relative pose (baseline 1)
triangulate inlier matches"]
  IFP -- "fails, try next pair" --> SP
  SP -- "seed_max_trials reached" --> NF(["return false"])
  IFP -- ok --> RNI["RegisterNextImage()"]
  RNI --> CAND["Candidates()
unregistered images linked to registered ones"]
  CAND --> HAS{"any candidates?"}
  HAS -- no --> FIN
  HAS -- yes --> P1["Pass 1: TryRegisterMulti()
images with ≥ 2 registered neighbors
rotation averaging + Resect()"]
  P1 -- "registered" --> ADD
  P1 -- "all failed (marked failed_)" --> P2["Pass 2: TryRegisterSingle()
one reference image, keep best score"]
  P2 -- "best score found" --> ADD
  P2 -- none --> FIN
  ADD["AddImage()
add 2D–3D observations of inliers
TriangulateImage() with registered neighbors"] --> BA{"bundle adjustment due?"}
  BA -- "every global_ba_interval" --> GBA["GlobalBundleAdjustment()
all registered images + FilterPoints"]
  BA -- "every ba_interval" --> WBA["WindowBundleAdjustment()
last ba_window images + FilterPoints"]
  BA -- "not yet" --> RNI
  GBA --> RNI
  WBA --> RNI
  FIN["final WindowBundleAdjustment()
if images were added since the last BA"] --> OK(["return true"])

An image that failed registration gets another chance as soon as an image it overlaps with is registered. A poor single-connection registration forces a window BA right away.

Each step: input, work, output

FunctionReadsDoesProduces
LoadImages() io.image_dir or io.images, cameras, image_cameras, trajectory
  • Builds one Image per file and assigns its camera
  • Loads GPS position priors (required for matching.mode: trajectory)
  • Reads the first image of each camera to fill missing width/height
 rec_.images, rec_.cameras, trajectory_priors.txt
ExtractFeatures() image files, sift params
  • Loads cached features if the SIFT-param hash matches
  • Otherwise reads grayscale and runs ExtractSift, then saves cache
  • UndistortKeypoints with the image's camera
 image.features (keypoints, descriptors, normalized), empty point_ids
MatchAndEstimateRops() features, matching, two_view, priors
  • SelectPairs: sequential, exhaustive or trajectory-based
  • MatchDescriptors (FLANN + ratio test, optional cross-check)
  • If ≥ min_matches: EstimateTwoViewGeometry (essential matrix, relative pose, inliers)
 view_graph_, cache/rops.bin; descriptors freed
RunIncremental() view_graph_, incremental
  • Seed pair, then register images one by one (see chart above)
  • Window / global BA along the way
 poses of registered images, 3D points, seed1_/seed2_
FinalTrackingAndBundle() registered images, view_graph_, final_ba
  • BuildTracks across all registered images (≥ min_track_length)
  • TriangulateTracks
  • rounds × BA (seeds fix the gauge) + outlier filtering
 final poses, points, refined intrinsics if enabled
Export() rec_, io.output_dir
  • ColorizePoints
  • Writes COLMAP text model, PLY, poses, omega-phi-kappa EOPs
 colmap/, points.ply, poses.txt, eops_opk.txt
GenerateOrtho() rec_, ortho (only if ortho.enabled)
  • GenerateOrthophoto in the map frame
  • WriteOrthophoto
